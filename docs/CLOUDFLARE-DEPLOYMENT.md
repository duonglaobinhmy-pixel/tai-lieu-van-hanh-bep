# Checklist triển khai Cloudflare

- [ ] Source đã đưa lên Git.
- [ ] Pages project đã tạo.
- [ ] Thư mục `functions/` được deploy.
- [ ] KV namespace đã tạo.
- [ ] Binding tên chính xác là `BBM_DATA`.
- [ ] Đã thêm duy nhất secret `PORTAL_PASSWORD`.
- [ ] Đã deploy production.
- [ ] Đăng nhập thành công.
- [ ] Lưu dữ liệu thành công.
- [ ] Mở máy khác thấy dữ liệu.
- [ ] Đã cấu hình custom domain.
- [ ] Đã bật Cloudflare Access/MFA nếu cần.
